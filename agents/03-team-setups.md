# 프로젝트별 추천 팀 구성

## A. commov 디퓨저 브랜드 런칭 + 카페24 (최우선)
비즈니스 애널리스트 → BI/BX → PM → 그래픽·영상 → 콘텐츠 → 데이터 애널리스트
흐름: 와디즈 펀딩으로 수요 검증 → 카페24 자사몰 → 큐텐 재팬·아마존

## B. officek3 B2B 공공·학교 영업
B2B 영업(S2B·나라장터) + 서비스 기획자(견적·후불·증빙) + 편집 디자이너(PDF 카탈로그) + 풀스택(견적 자동 발행)

## C. 자체 문구 브랜드 (캐릭터 IP)
PO + 일러스트레이터 + BI/BX + 콘텐츠 + PM(중국 소싱 vs 국내 인쇄 단가)
스티커·메모지·키링은 원가율 10~20%

## D. 베이커리 온라인 유통
PM(냉동생지·구움과자 선물세트, 식품제조가공업 허가 확인) + 콘텐츠 + B2B 영업(기업 선물) + 비즈니스 애널리스트(매각가 20억+ 매출 구조)

## E. 사업체 공동관리 AI 앱
PO + UX 기획자 + UI/UX 디자이너 + 풀스택 + AI/ML 엔지니어 + CTO
우선순위 최하: 실물 브랜드 현금흐름 확보 후 착수

## F. 수출 (공통 확장)
