# AI 에이전트 팀 (1인 회사 운영 시스템)

## 구조
```
agents/
├── 00-company-context.md      # 모든 에이전트 공통 회사 정보 (맨 위에 붙여 넣기)
├── 01-prompt-template.md      # 새 에이전트를 만들 때 쓰는 7칸 틀
├── 02-role-map.md             # 48개 직무 특징 + 지금/나중/불필요 분류
├── 03-team-setups.md          # 프로젝트별 추천 팀 구성
├── prompts/                   # 핵심 에이전트 10개 프롬프트
└── projects/
    └── commov-launch/         # 실제 실행 결과물 (CEO → PM, BI/BX)
```

## 사용법
1. Claude 프로젝트(또는 GPTs)를 에이전트 1개당 1개씩 만든다.
2. 지침란에 `00-company-context.md` + `prompts/XX.md` 내용을 붙여 넣는다.
3. 브랜드북, 원가표 등 자료는 프로젝트 파일로 올린다.
4. 각 출력 끝의 "→ 다음 담당" 내용을 다음 에이전트에 그대로 전달한다.

## 시작 순서
CEO → PM → 콘텐츠 디자이너, 3개로 2주 운영한 뒤 병목 직무를 추가한다.

## 주간 리듬
- 월: CEO가 이번 주 과제 3개와 담당 배분
- 수: 실무 에이전트 작업
- 금: 데이터 애널리스트 리포트 → CEO가 다음 주 계획
