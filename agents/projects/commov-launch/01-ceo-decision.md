## 2. 제1원리 분해

### 2-1. 고객이 실제로 사는 것은 무엇인가

| 겉으로 사는 것 | 실제로 사는 것 | 시사점 |
|---|---|---|
| 향이 나는 액체 | "내 공간·옷에서 좋은 냄새가 난다"는 **기분과 정체성** | 원료값이 아니라 **향 이름·스토리·사용 장면**이 가격을 정한다 |
| 디퓨저/스프레이 용기 | **매일 손이 가는 의식(ritual)** | 사용 빈도가 높을수록 재구매가 빨리 온다 → 뿌리는 제품이 꽂아두는 제품보다 유리 |
| 브랜드 | **남에게 선물해도 창피하지 않다는 보증** | 패키지와 첫인상에 투자하고, 향 개발은 OEM 기성 베이스로 끝낸다 |
| 냄새 제거 | 겨울 실내건조 냄새·옷 냄새 **문제 해결** | "실내건조 쉰내 커버"가 가장 강한 구매 이유. 구글 트렌드 '실내건조' 관심도가 2025-26 겨울에 2023년 겨울 대비 약 2배였다([MTN](https://news.mtn.co.kr/article/2026111818344363643)) |

결론: 우리가 파는 것은 **"향 취향 + 일상 의식 + 냄새 문제 해결"**이다. 원료는 OEM 기성품, 돈은 이름·패키지·콘텐츠에 쓴다.

### 2-2. 원가율 1~30%가 가능한 구조

향 제품은 판매가에서 액체 원가가 차지하는 비중이 작다. 원가를 끌어올리는 것은 **용기·패키지·소량 MOQ**다. 그래서 아래 규칙을 지킨다.

1. **향료는 OEM 보유 베이스를 쓴다.** 자체 조향 R&D 0원. 향 3종만.
2. **용기는 기성 PET 스프레이(200ml)를 쓴다.** 커스텀 금형·유리병은 금지.
3. **단상자 1종 + 라벨만 바꿔 3향을 만든다.** 인쇄 판 1개로 SKU 3개.
4. **판매가는 원가의 4배 이상으로 정한다.** 원가율 25% 이하가 아니면 출시하지 않는다.

섬유향수 200ml 단위 원가 추정 (**전부 가정**, PM이 견적 3곳으로 검증):

## 3. 첫 진입 상품 후보 3개 비교

| 기준 | A. 섬유향수 200ml | B. 리드 디퓨저 200ml | C. 오드퍼퓸 30ml |

| 예상 판매가 | 19,900원 (2개 35,900원) | 29,000원 | 39,000원 |

| 재구매 주기 | **4~6주** (매일 사용) | 2~3개월 | 4~6개월 |
| 수출성 | 상: 무알코올(수성) 처방이면 항공 위험물 회피 쉬움, 가볍고 안 깨짐 (가정) | 중: 유리 파손·용제 인화성 → 항공 배송·반품 비용 큼 | 하: 알코올 고함량 = 항공 위험물, 일본은 현지 화장품 제조판매업 파트너 필요 |
| 실행 난이도 | **하**: 생활화학제품 안전기준 확인·신고 1건 | 중: 동일 신고 + 파손 테스트 + 포장 설계 | 상: 화장품 책임판매업 등록, 표시광고 규제 |

| 와디즈 적합성 | 상: "실내건조 냄새" 문제 해결형 스토리 | 중: 디퓨저 카테고리 이미 포화 | 중: 향수 펀딩은 체험 없이 구매 장벽 큼 |

**추천: A. 섬유향수 200ml.** 원가율이 가장 낮고, 재구매가 가장 빠르고, 수출 장벽이 가장 낮다. B는 A가 재구매율 20%를 넘긴 뒤 같은 향 3종으로 확장한다. C는 1년 안에는 하지 않는다.

> 확인 필요: 섬유향수·룸스프레이는 국내에서 방향제/탈취제로 분류되어 「생활화학제품 및 살생물제의 안전관리에 관한 법률」상 안전확인대상 생활화학제품 신고·표시 대상일 가능성이 높다(가정). 이 신고가 끝나기 전에는 와디즈 오픈을 하지 않는다.

## 5. 중단·삭제할 일

1. **디퓨저·캔들·향수 동시 개발 → 중단.** SKU는 섬유향수 1종, 향 3종만.
2. **자체 조향·조향사 외주 → 삭제.** OEM 보유 베이스에서 고른다.
3. **커스텀 유리병·금형 → 삭제.** 기성 PET 용기만 쓴다.
4. **오픈마켓(쿠팡·스마트스토어) 동시 입점 → 90일간 보류.** 가격 경쟁에서 지는 구조. 와디즈와 자사몰에서 가격 기준점을 먼저 만든다.
5. **오프라인 팝업·박람회 → 삭제.** 대표 시간 대비 매출 근거 없음.
6. **향 10종 이상 라인업 기획 → 삭제.** 3종이 다 팔리기 전에는 4번째 향을 만들지 않는다.
7. **브랜드 슬로건·세계관 문서 장기 작업 → 1주로 제한.** W3 안에 끝낸다.
8. **대표가 직접 포장·CS → 금지.** 금산 직원 1명과 카페24 자동 응답으로 처리한다.

## 6. 에이전트별 지시

→ **PM:** 섬유향수 200ml(PET 스프레이, 무알코올 수성 처방 우선) OEM 견적을 **3곳 이상**에서 11/30까지 받아라. 조건은 MOQ 1,000개 이하, 단위원가(내용물+용기+라벨+단상자) **4,000원 이하**, 납기 3주 이내. 생활화학제품 안전확인 신고 대상 여부와 비용·기간을 12/7까지 확인하라. 와디즈 일정은 공개예정 12/15, 펀딩 1/5~1/25 3주, 목표 금액 1,000만 원(내부 목표 2,200만 원)으로 잡아라. 판매가 19,900원, 2개 세트 35,900원, 얼리버드 31,900원이다. 2-2의 원가표를 견적이 나오는 대로 갱신하고, 원가율 25%를 넘으면 즉시 보고하라.

→ **BI/BX:** 상품은 **섬유향수 200ml, 향 3종**이다. 판매가 19,900원이므로 "프리미엄이지만 매일 뿌려도 부담 없는" 톤을 잡아라. 타깃은 **25~39세 1~2인 가구 여성, 원룸·오피스텔 거주, 겨울철 실내건조 냄새와 옷 냄새가 고민인 사람**이다. 보조 타깃은 같은 연령대의 선물 구매자다. 산출물은 12/14까지: ① 브랜드명 commov 유지를 전제로 로고 2안, ② 향 3종의 이름과 한 줄 스토리(사용 장면 중심: 출근 전 셔츠, 실내건조 빨래, 침구), ③ 기성 PET 용기에 붙일 라벨과 단상자 1종(라벨만 바꿔 3향 구분), ④ 와디즈 상세페이지 헤드카피 3안. 핵심 메시지는 "실내건조 냄새를 내 향으로 바꾼다"다. 일본어 라벨 병기가 가능한 레이아웃으로 설계하라(Qoo10 Japan 확장 대비).

→ **마케팅(다음 단계):** W4부터 와디즈 알림신청 300명을 목표로 숏폼 10개 기획. 예산 상한 월 300만 원.
