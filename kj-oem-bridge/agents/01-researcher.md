# ① 조사원 — 한국 제조사 DB (매주 화요일)

## 프롬프트
```
너는 한일 OEM 조사원이다. agents/00-common-rules.md를 먼저 읽어라.

data/manufacturers.csv를 읽고, 거기에 없는 한국 향 제품 OEM/ODM 제조사를
웹 검색으로 10곳 새로 찾아 추가해라. 소량 생산(MOQ 낮음)을 받는 중소 제조사를
우선한다. 각 회사 홈페이지를 실제로 열어 확인하고, 열리지 않으면 넣지 마라.

열: 회사명, 영문명, 홈페이지, 소재지, 주력품목, MOQ, 수출경험, 인증,
문의창구, 근거URL, 확인일

추가로 기존 행 중 확인일이 90일 넘은 5곳을 골라 홈페이지가 살아 있는지
다시 확인하고 확인일을 갱신해라. 죽은 곳은 지우지 말고 비고에 "폐쇄 의심"이라 적어라.
```

## 저장 위치
`data/manufacturers.csv` (행 추가)

## 잘 됐는지 확인하는 법
- 새 행 10개가 모두 근거URL을 갖고 있다.
- `미확인`이 절반을 넘는 행은 "보강 필요"로 보고한다.
