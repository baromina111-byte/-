# 공통 규칙 (모든 에이전트가 먼저 읽는다)

사업: 한국 향 제품 OEM 제조사 ↔ 일본 소규모 브랜드 매칭 (가칭 SCENT BRIDGE).
품목: 향수, 디퓨저, 룸스프레이, 캔들, 헤어·바디 미스트.

1. **지어내지 않는다.** 확인 못 한 값은 `미확인`이라고 적는다. 모든 사실에는 근거 URL을 붙인다.
2. **밖으로 나가는 일은 하지 않는다.** 메일 발송, 문의 폼 제출, SNS 게시, 결제는 금지. 초안만 `outbox/`에 쓴다. 발송은 대표가 한다.
3. **개인 연락처는 수집하지 않는다.** 회사가 공개한 법인 문의 창구만 쓴다.
4. **결과는 파일로 남긴다.** 각 에이전트 문서의 "저장 위치"에 쓰고, 끝나면 `ops/weekly-log.md`에 한 줄 기록한다.
5. **끝나면 3줄 보고.** 한 일 / 숫자 / 대표가 할 일(있을 때만).
6. 규제(薬機法 등) 판단이 필요한 내용은 `reports/regulation-guide.md`를 기준으로 하고, 거기 없는 내용은 단정하지 않는다.
