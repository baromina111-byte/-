# 데이터 출처

## 공장등록 검증과 후보 명단
- 출처: 한국산업단지공단 전국등록공장현황(2025-12-31 기준), 공공데이터포털 https://www.data.go.kr/data/15105482/fileData.do (무료, 인증키 불필요, 연 1회 갱신)
- 원본 규모: 220,705개 공장 (회사명, 산업단지명, 생산품, 공장주소)
- `manufacturers.csv`의 `공장등록` 열: 회사명이 명단과 일치하면 `확인`. `명단에서 미발견`은 미등록을 뜻하지 않는다. 소규모 공장은 등록 의무가 없고, 상호와 브랜드명이 다를 수 있다.
- `candidates-factory-register.csv`: 등록 생산품에 디퓨저·방향제·캔들·향초·양초·향수·섬유향수·룸스프레이·인센스가 들어간 공장 중 기존 DB에 없는 곳. 생산품은 등록 당시 자가 기재라 현재와 다를 수 있고, OEM 수주 여부는 알 수 없다.

## 아직 연결하지 못한 것
- 식약처 화장품 제조업·책임판매업 API (`apis.data.go.kr/1471000/CsmtcsMfcrtrInfoService02`): 공공데이터포털 인증키가 필요하다. 키 발급 후 화장품 제조업 등록 여부와 GMP 여부를 붙인다.
