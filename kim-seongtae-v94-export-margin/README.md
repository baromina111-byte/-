# 김성태전: 제국의 시대 v9.4

v9.3(채널 충돌·미수금)을 반복하지 않고 다음 세 축을 새로 얹었습니다.

1. **원가율 엔진** — 품목별 판매가·제조원가·채널수수료·물류비를 분해해 단위 기여이익과 기여이익률을 계산합니다. 목표 원가율 5~30% 밴드를 색으로 표시하고, 50%를 넘는 품목은 "구조적 적자위험"으로 경고합니다.
2. **수출 데스크** — 미국·일본·동남아·중동 4개 시장. 인증비를 선집행해 인증 기간(2~3개월)을 통과해야 진출이 열립니다. 관세·현지물류·가격배수·수요계수를 반영한 FOB 기준 기여이익으로 판단합니다.
3. **환율 리스크** — USD/KRW와 수입 원자재 비중을 함께 관리합니다. 환율 상승은 수출 대금을 늘리는 동시에 수입 원가를 올리므로, 수출비중이 수입원가 비중보다 커야 순이익이 늘어납니다.

여기에 **월순익 1억 달성률 게이지**가 대시보드에 상시 표시됩니다.

## 신규 사건

- COMMOV 미국 MoCRA 등록 요구 (자가 등록은 40% 확률로 반려)
- 환율 급등 1,455원 (선물환 헤지 / 수용 / 국산 전환)
- 오피스K 역마진 경보 (자체 제조 전환 / 번들 재구성 / 단종)
- 아마존 FBA 입고 4주 지연
- D&J 일본 셀렉트샵 홀세일 제안

## 시뮬레이션 반영 항목

내수 채널 적합도 → 품목 기여이익 → 수출 기여이익 → 환율 효과 → 광고비 → 미수금 자동회수 → 차입 이자. 운영 집중도에 **원가절감** 모드가 추가되어 매달 전 품목 원가를 3%씩 낮춥니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 엽니다. 별도 빌드가 필요 없습니다.

COMMOV 제품 이미지는 같은 폴더에 `car-air.png`를 두면 우선 표시되며, 파일이 없을 때는 브랜드 색상 패널로 안전하게 대체됩니다.
