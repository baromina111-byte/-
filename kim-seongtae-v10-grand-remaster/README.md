# 김성태전: 제국의 시대 v10.0 — GRAND REMASTER

v9.3(채널 리스크)에서 **그래픽 전면 재작성 + 경영 시스템 확장**을 진행한 버전입니다.
빌드 없이 `index.html` 하나만 열면 실행됩니다.

## 실행

```bash
# 아무 정적 서버나 사용
python3 -m http.server 8080
# → http://127.0.0.1:8080/kim-seongtae-v10-grand-remaster/
```

또는 `index.html`을 Chrome / Edge / Safari에서 바로 엽니다.

## 그래픽 (v9.3 대비)

전부 **인라인 SVG + CSS**로 렌더링합니다. 외부 이미지에 의존하지 않으므로
`car-air.png` 누락이나 외부 CDN 차단으로 깨지던 문제가 사라졌습니다.

- 떠다니는 3중 그라디언트 배경 + SVG 필름 그레인
- 브랜드별 절차적 생성 키아트 — 브랜드 ID 해시로 스카이라인·입자를 생성하고, 브랜드 고유 색으로 그라디언트와 광택 스윕을 입힘
- 브랜드 4종 전용 크레스트 SVG (방향제 / 문장 / 문서 / 밀 이삭)
- 실적 추이 4계열 라인·영역 차트 (그리기 애니메이션), 지표 타일별 스파크라인과 전월 대비 증감
- 글래스 패널, 골드 헤어라인, 진행 미터 광택, 버튼 스파크, 토스트 스택, 결산 모달
- Noto Sans KR + Outfit(숫자 tabular) 웹폰트, 폴백 스택 지정
- 모바일 6탭 하단 내비게이션, `prefers-reduced-motion` 대응

## 게임 시스템 (신규)

| 시스템 | 내용 |
|---|---|
| 난이도 | 쉬움 / 보통 / 어려움 — 시작 자본·부채·금리·사건 빈도·변동성·목표가 모두 달라짐 |
| 승패 조건 | 목표 순자산 달성 시 승리, 현금 고갈 + 추가 차입 불가 시 파산 |
| 시장 사이클 | 호황(×1.20) / 보통(×1.00) / 불황(×0.80)이 2~5개월 주기로 전환, 남은 개월 수 표시 |
| 신용등급 | AAA~D 8단계. 부채비율·평판·부실이력·현금으로 산정하며 금리·대출한도·회수율에 직접 반영 |
| 자금 조달 | 등급별 한도 내 대출, 부채 상환, 지분 매각(투자 유치, 40% 하한) |
| 조직 | 영업(매출 +4%/인) · 마케팅(브랜드력 +0.7/월/인) · 재무(회수율 +3%p/인), 인건비가 매달 순익에서 빠짐 |
| 복리 성장 | 브랜드력·광고비·시장 국면이 매달 브랜드 규모를 복리로 키우고, 채널 충돌이 이를 갉아먹음 |
| 채널 전략 | DTC/B2B/혼합/지역 — 매출 배수와 **충돌 표류(월간 증감)**가 트레이드오프 |
| 계약 | 회수기한(30/60/90일)이 단가에 반영, 선금 비율이 총액을 깎음, 거래처별 부실 확률, 조기정산(-7%) |
| 사건 | 고정 서장 4건 + 랜덤 풀 16건. **기한 내 미처리 시 가장 불리한 선택지가 자동 적용** |
| 업적 | 12종 |
| 기록 | 최대 48개월 히스토리, 통산 기록(누적 매출·최고 순익·부실·차입) |
